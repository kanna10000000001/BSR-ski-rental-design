# 板上有雪 BSR 滑雪租赁系统

本仓库是《系统分析与设计》课程作业的源码与报告提交包。项目以 BSR 两门店扩张场景为背景：顾客使用微信小程序浏览装备、填写预约清单和查看本人记录；员工、负责人和维修承包商使用网页管理端处理合同、归还、维修、库存和排班。

## 课堂演示范围

- 小程序：在微信开发者工具中本地编译演示装备浏览、预约清单和我的记录。
- 网页管理端：可演示工作台、四阶段预约受理、客户业务时间线、三步开单、逐件归还、换装、维修验收、排班及经营报表 CSV 导出。
- 数据：仅使用虚构课堂演示数据。
- 边界：未开通微信云开发；不接入真实支付、签字、短信或公开发布；不宣称真实手机端云同步、生产部署或性能测试已经完成。

## 报告与源码

- [课程提交版实验报告](reports/徐令宜_BSR系统分析与设计报告.pdf)：43 页，按 A 业务建模、B 需求、C 分析、D 设计编排；B.12 为 UC01 完整用例规约，D 部分说明总体结构、数据、事务、模块、界面及验证，参考资料置于最后。
- `miniprogram/`：顾客端微信小程序。
- `web-admin/dist/`：网页管理端静态前端。
- `cloudfunctions/`：课堂原型的云函数源码；未完成微信云开发关联时，不应把它视为已联通的手机端服务。
- `tests/`：业务规则、权限与页面流程测试。
- `双端使用说明.md`：本地演示步骤与业务规则说明。
- `docs/UC01_开立租赁合同_用例规约.md`：按基本路径、扩展路径、字段和业务规则写出的核心用例规约，与报告 B.12 对应。
- `docs/数据库结构与迁移说明.md`：云端数据库的实际结构、数据迁移步骤和当前边界。

## 本地查看

1. 用微信开发者工具导入仓库根目录（选中含 `project.config.json` 的文件夹），点击编译；当前默认启用本机演示模式。需要测试已关联的云环境时，再将 `miniprogram/config.js` 中的 `demo` 改为 `false`。如果开发者工具本身无法启动，先检查其安装或登录状态，项目源码检查不能代替工具中的实际编译。
2. 若要查看网页管理端本机演示，在仓库根目录执行 `node scripts/preview-web.js`，再打开 `http://127.0.0.1:8077`。
3. 修改共用业务规则后执行：

```powershell
node scripts/sync-domain.js
node --test tests/*.test.js
node scripts/check.js
```
